# Security Policy

## Supported versions

This project is maintained on the `main` branch and is intended for active use on the current release.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use one of the following:

- GitHub Security Advisory for this repository
- Direct contact with the maintainer

## Safe handling

Do not run untrusted documents in a production environment without an isolated sandbox. The tool should be used only on files that you have explicit permission to inspect.
